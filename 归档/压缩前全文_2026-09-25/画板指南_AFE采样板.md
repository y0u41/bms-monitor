## 0. 十句话把原理说清（先把这节读完，否则后面全是"抄动作不知所以然"）

| # | 一句话 | 你该怎么用它 |
|---|---|---|
| 1 | **画 PCB = 把一张"连线表"翻译成铜箔** | 你手上已经有那张表（`Tech_Design.md` §3.1.1 的 20 行），本指南只是教你怎么把它交给工厂 |
| 2 | **网络（Net）= 一根导线的名字** | 同一个名字的焊盘**必定连在一起**，工具自动完成。⛔ 不要靠"画线"连长距离，用**网络标签** |
| 3 | **封装（Footprint）≠ 原理图符号** | 符号是逻辑，封装是那块金属焊盘的尺寸。⛔ **一律用立创商城现成封装，不要自画**（自画封装是新手翻板子的第一大户） |
| 4 | **两层板 = 顶层走信号，底层铺地** | 本板 §3.1.1 ⑤ 明确 2 层即可，不用四层 |
| 5 | **线宽决定载流能力** | 关键好消息：**这块板上没有任何一根走线要过 15A** —— `Rsns` 的电流从**端子焊盘**进出，不经细线（C-70 的决策） |
| 6 | **单点地 / Kelvin = 本板唯一"画错就不工作"的概念** | 所有小电流地汇聚到 `VSS` 一个点；`SRP`/`SRN` 从 `Rsns` 本体两端**单独**引出（§3.1.1 ⑤） |
| 7 | **丝印 = 印在板上的字** | 靠它执行 S18 的"从 B− 往 B+ 逐串"，也靠它防止三个月后你自己接错 |
| 8 | **DRC 只查"间距/断路"，不查"接对没接对"** | ⛔ **DRC 全绿 ≠ 板子对**。§5 的人工复核表才是真关卡 |
| 9 | **Gerber = 工厂读的最终格式** | 你交出去的是它，不是 `.epro2` 工程文件 |
| 10 | **一次做对远便宜过返板** | 打样 ¥30 + **2~3 天物流**；本项目只有 09-29 前的窗口，返一次就撞硬截止 ⇒ 复核值得花时间 |

## 3. 第二步：原理图（约 2.5 小时，按五组分五次画）

### 3.0 三条通用纪律（每组都用）

1. ⛔ **不要一根线一根线拉过去连**。做法：把元件摆好 → **放置 → 网络标签（Net Label）**（快捷键常为 `N`）→ 在每个引脚 stub 上点一下 → 输入网络名。**同名即同连**。
2. ⭐ **网络名照抄下表**（不要自己发明，后面 PCB 复核、和三个月后的你都要靠它对上 §3.1.1 的表）：

| 网络名 | 含义 | 出现位置 |
|---|---|---|
| `PACK_P` | 电池包正极（第 4 串上端 = T4） | `BAT`(经`Rf`)、`REGSRC`、`VC5`(经`Rc`) |
| `PACK_N` | ★ **纯高电流节点**：`Rsns` 的**电池侧电流脚（脚 1）** + KF128 进线端子 | `J2` 两脚、`Rsns` 脚 1 |
| `RSNS_SP` | ★ **电池侧 Kelvin 参考点**：`Rsns` 的**取样脚 2** | `VSS`(经 `R19`)、`VC0`(经`Rc`)、`SRP`(经`RFILT`)、`J1.1`(T0) |
| `RSNS_SN` | ★ **开关侧 Kelvin 取样点**：`Rsns` 的**取样脚 3** | `SRN`(经`RFILT`) |
| `SW_N` | ★ **纯高电流节点**：`Rsns` 的**开关侧电流脚（脚 4）**（往 B 板 FET 方向） | `J3` 两脚、`Rsns` 脚 4 |
| `CELL1` / `CELL2` / `CELL3` | 线束 T1 / T2 / T3 | `VC1` / `VC2` / `VC3`+`VC4`(各串`Rc`) |
| `AFE_I2C_SDA` / `AFE_I2C_SCL` | → MCU PD12 / PD11 | 经 100Ω 到 `SDA`/`SCL` |
| `AFE_ALERT` | → MCU PD13 | `ALERT` 脚 |
| `AFE_BOOT` | ← MCU PE6 | 经 1K 到 `TS1` |
| `V3V3_MCU` | ★ **从 MCU 板引来的 3.3V**，只给 I²C 上拉用 | 两个 4.7K 的上端 |
| ~~`GND_SIG`~~ | **已取消**（与 `VSS` 合并） | 原表与 §3.1 自查判据自相矛盾：这里写"电容地落 `GND_SIG`"，§3.1 又写"电容地落 `VSS`"。⛔ **全板只用 `VSS`** |
| `VSS` | ★ **小电流地**（唯一地网）：U1 脚 3 + 全部去耦电容地 + `Rts1`/`Ralert`/`Calert` + `J4.8`/`J5.5` | 经 **`R19`（0Ω）单点**入星到 `RSNS_SP` |

3. ⚠️ **每放一个元件，立刻在它旁边打一个"手写在便签纸/纸上"的勾**，别相信"我记得连过了"。

### 3.1 分组 A：电源与去耦（15 分钟）

| 要放 | 连成 | 依据 |
|---|---|---|
| `BAT` 脚 → `Rf` **100Ω** → `PACK_P`；`Cf` **4.7µF** + **0.1µF** 紧贴脚 10 到 `VSS` | `PACK_P` | §3.1.1 ① 脚 10（§7.6/§10，"紧贴 IC"） |
| `REGSRC`(脚 9) 与 `BAT` **同网络**（`Rf` 之后）+ **1µF** 到 `VSS` | `PACK_P` | 脚 9（✅ §10：76920 **不需要** cascode FET） |
| `REGOUT`(脚 8) → **4.7µF** 到 `VSS`，★ **不接任何负载** | 新网络 `REGOUT` | 脚 8；⛔ 别把它当 3.3V 电源给板上别人用 |
| `CAP1`(脚 7) → **1µF** 到 `VSS` | 新网络 `CAP1` | 脚 7（表 9-1 "A capacitor must be installed"） |
| 脚 11 `NC` → **悬空**（可留测试点） | 无网络 | 脚 11（✅ 已核实：表 6-1 对 76920 明写 **No connect**） |

**画完自查**：`REGOUT`/`CAP1`/`Cf` 三处电容**另一端是否都落在 `VSS`（不是 `SW_N` / 电流节点）**？⛔ 常见错：把去耦电容接到了"地符号"上，而那个地在别处连到了开关侧。

### 3.2 分组 B：六路单体电压采样（30 分钟，最容易漏的一组）

1. 放 **6 个 100Ω（`Rc`）** + **6 个 1µF（`Cc`）** + **1 个 5 位线束座**（T0~T4）。
2. 逐路连（照 §3.1.1 ① 脚 12~17 与 ② 表）：

| 路 | 线束 | → `Rc` 100Ω → | 该脚上再挂 | 落点 |
|---|---|---|---|---|
| 1 | T0 `PACK_N` | `VC0` | — | `Cc` 1µF → `VSS` |
| 2 | T1 | `VC1` | — | 同上 |
| 3 | T2 | `VC2` | — | 同上 |
| 4 | T3 | `VC3` **和** `VC4` | ★ **两脚短接后各串一颗 100Ω** | 同上（两颗 `Cc`） |
| 5 | T4 `PACK_P` | `VC5` | — | 同上 |

> ⛔ **本组唯一的"必错点"**：忘记 **`VC4`-`VC3` 短接**（表 9-2 的 4 Cells 列写的是 short）。漏了它 ⇒ 通道编号整体错位、过压保护测错那一路，而且**读数看起来仍是合理的电压**。
> ⚠️ 另一处易混：`VC5` 走**信号路径**（100Ω+1µF），`BAT` 走**电源路径**（`Rf`+`Cf`）—— 两者都从 `PACK_P` 出发，但**是两条分开的线**，不许合在同一个 100Ω 上。

### 3.3 分组 C：电流采样 `Rsns`（20 分钟，★ 本次新增，没有它就没有硬件层保护）

| 要放 | 怎么连 | 依据 |
|---|---|---|
| `Rsns` = **`PBV-R005-F1-1.0`**（立创 `C2688848`）**5mΩ ±1% / 10W / ±75ppm/℃ / SIP-4 四端子**。★ 封装 = 库内现成 `SIP-4_PBV-R005-F1-0.5`，⛔ 不要自画、⛔ 不要用 0805 | **脚 1/4 = 电流脚**（大焊盘）⇒ 两端 = `PACK_N` 与 `SW_N`；**脚 2/3 = 取样脚**（小焊盘）⇒ `RSNS_SP` / `RSNS_SN` | §3.1.1 ③ + **③-b**（脚位依据 LCEDA 官方焊盘图）；C-72 |
| **2 个 KF128-5.08-2P-AA**（立创 `C474952`；★ 库内参数**额定 24A / 250V / 2.5mm²**，见 §3.1.1 ③-c / C-74） | 一进 `PACK_N`、一出 `SW_N`，★ 主电流只走端子焊盘 | ③"位置"行 + S22（⛔ KF301 仅 10A） |
| `SRP`(脚 18) → 经 **100Ω（`RFILT`）** → **`Rsns` 脚 2（`RSNS_SP`）** | 并 **0.1µF** 到 `VSS` | ① 脚 18（§9.1.5：`SRP` 靠 `VSS`，= **电池侧取样脚**） |
| `SRN`(脚 19) → 经 **100Ω** → **`Rsns` 脚 3（`RSNS_SN`）** | 并 **0.1µF** 到 `VSS` | ① 脚 19 |
| `VSS`(脚 3) | **不直接接电流节点** —— 经 `R19`（0Ω 星形跳线）接到 **`RSNS_SP`**（电池侧 Kelvin 点） | ③-b ②（单点星形地） |
| **`R19` 0Ω 0805** | 一端 `VSS`、一端 `RSNS_SP`，★ **布在星点**（紧贴 `Rsns` 脚 1） | ★ **全板小电流地只有这一个入口** ⇒ 星形地无法被绕过 |

> ⛔ **两条绝不能错的纪律**（错了 = 硬件层过流/短路保护**静默不存在**，且一切读数正常）：
> ① **`SRP` 必须取自 `Rsns` 脚 2（电池侧）、`SRN` 必须取自脚 3（开关侧）** —— 四端子件的**电流脚 1/4 与取样脚 2/3 是不同焊盘**，⛔ 接到 1/4 就是把主电流灌进取样网络；两脚对调则落在对面端点（C-70 / C-75）；
> ② **Kelvin 分开走**：取样从 `Rsns` 的**取样脚 2/3** 单独引出细线，⛔ **不许从电流脚 1/4（大焊盘）取、也不许搭在主电流的端子铜箔上**。
> ★ **判据（写进 §5 复核表）**：原理图上从 `Rsns` 焊盘出发，到 `SRP`/`SRN` 只有"100Ω + 0.1µF"两个元件，中间**不串任何其它东西**。

### 3.4 分组 D：BOOT + TS1 + ALERT（20 分钟，三条红线里占两条）

| 要放 | 怎么连 | 依据 |
|---|---|---|
| **10K**（`TS1` 下拉） | `TS1`(脚 6) → `VSS` | ✅ 表 6-1 注(1)「若不使用，用 10K 标称值下拉到 VSS」+ §9.1.6 |
| **1K 串阻 + 微动按键 + PE6 排针** | `AFE_BOOT`(=MCU PE6) → **1K** → `TS1`；★ **备份按键**：`V3V3_MCU` → **另一个 1K** → **同一个 TS1 节点**（MCU 没跑起来时手按即可 boot，等价于 EVM 上的 `S1 BOOT`）。⛔ **绝对不要把按键接到 `PACK_P`** —— `TS1-VSS` POR 后绝对最大只有 **3.6V**（§7.1），12V 一按就烧 | C-64 / §3.1.1 ① 脚 6 |
| **499K**（`RALERT` 下拉） | `ALERT`(脚 20) → `VSS` | C-68 + §9.1.4（⛔ **禁止任何上拉**） |
| **470pF** | `ALERT` → `VSS` | §9.1.4 原文推荐 500K+470pF；★ 必须配 **499K**（1M×470pF = 470µs > 上限 250µs，499K×470pF = 234µs ✓） |
| 排针 1 脚 | `ALERT` → **`AFE_ALERT`**（→ MCU PD13，**MCU 侧浮空输入**） | C-68：PD13 内部上拉 40K 会复现同一故障 |

> ⛔ **红线自查**：`ALERT` 网络上**除了 499K、470pF 和去 PD13 的线，不许出现任何别的元件**（尤其不许有上拉到 3.3V）；`TS1` 上**不许长期接高电平**（脉冲脚，不是使能脚）。

### 3.5 分组 E：I²C 出线 + CHG/DSG 去 B 板（15 分钟）

| 要放 | 怎么连 | 依据 |
|---|---|---|
| **2 个 4.7K**（SDA/SCL 各一） | 上端接 **`V3V3_MCU`**（从 MCU 板经排针引来的 3.3V），下端接各自总线 | §3.1：⛔ 禁止 5V（REGOUT/ALERT 绝对最大 3.6V）；★ 上拉电源**必须取 MCU 侧 3.3V**，防"幽灵供电" |
| **2 个 100Ω** | 串在 `SDA`/`SCL` 与排针之间 | §3.1 |
| **`J4` = XH2.54-8P**（立创 `C9900000730`，**防呆+锁扣**） | `AFE_I2C_SDA` / `AFE_I2C_SCL` / `AFE_ALERT` / `AFE_BOOT` / `EN_CHG` / `EN_DSG` / `V3V3_MCU` / `VSS` | S6：I²C 总线**独占**；★ 合并了原"5 位排针 + 单独 PE6 排针"；★ 插反/错位一格物理不可能 |
| **`J5` = XH2.54-5P**（立创 `C9900017328`，**防呆+锁扣**） | `DSG`(脚 1)、`CHG`(脚 2)、`EN_CHG`、`EN_DSG`、`VSS` | §3.1.1 ① 脚 1/2：⛔ **外部不加下拉、不加缓冲**，走线短 |

> ⚠️ **`DSG`/`CHG` 电压域**：手册允许 0~16V，`VCHG_CLAMP` 18/20/22V ⇒ ⛔ 绝对不要把这两根线和 `PACK_P`(14.6V) 之外的任何**功率网络**并排短距离走，也不要误接成 3.3V 域。

### 3.6 原理图收尾（15 分钟）

1. ☐ **ERC / 电气规则检查**（菜单常为 **设计 → 检查 ERC**）：处理所有"引脚未连接"告警。**唯一合法处理方式是去连上它**，⛔ 不是加 `No ERC` 标记（脚 11 NC 例外）。
2. ☐ ⭐ **网络表人工对册**：导出/打开网络表（**设计 → 网表 / 或 PCB 里的"参考 → 网表"**），把 §3.1.1 ① 的 20 行**逐行**对着念一遍："这个脚名旁边的网络名，和表里写的一致吗？" 20 行、每行 10 秒、共 3 分钟，**这是本指南性价比最高的 3 分钟**。

### 4.2 设计规则（10 分钟，先设再布）

**设计 → 设计规则 / 线宽**：

| 网络类别 | 最小线宽 | 来源 |
|---|---|---|
| 信号（`VCn`、I²C、`ALERT`、`BOOT`） | **≥0.30 mm** | §3.1.1 ⑤ |
| 3.3V / `REGOUT` / `CAP1` | **≥0.50 mm** | 同上 |
| `Rsns` 主电流路径 | ⛔ **不用走线** —— 用端子焊盘 + **大面积铺铜 + 阻焊开窗上锡** | 同上（主电流不过板） |
| 间距（默认） | ≥0.2mm；★ **`PACK_P`(14.6V) 与 3.3V 域之间 ≥0.5mm** | ⚠️ 待核：嘉立创两层最小间距按其工艺能力，下单页会提示 |

### 4.3 布线（1 小时，按此顺序 = 先难后易）

1. **先布 `SRP` / `SRN` / `VSS` 三条（全板最关键）**：从 `Rsns` **本体两端**各拉一根细线（经 100Ω）到 `SRP`/`SRN`；`VSS` 单独一根直接回 AFE 脚 3。★ 三条线**平行、短、远离功率铜箔**；⛔ 不许让主电流从这三根线里借道。
2. **单点地星形链**：`VSS` 脚 → 依次接 `Cc` 的接地端 → `Cf`/`REGOUT`/`CAP1` 电容地 → `RALERT`(499K) 地 → **最后**才接到 `Rsns` 电池侧（= `PACK_N`）。★ **顺序单链**，⛔ 不要画成一个地平面让大家随便戳（§11.1）。
3. **底层铺地**：Bottom 层铺 `GND`（连到 `VSS` 单点），★ **但在 `Rsns` 与两个功率端子正下方挖空/开槽**，阻断功率地电流污染 Kelvin。
4. **`Cc`/`Rf`/`Cf` 去耦**：电容**紧贴引脚**，⛔ 不要绕一圈再回来。
5. **`ALERT` 走线**：最短，★ 两侧各画一条 `GND` 细线包住（**guard 环**，§9.1.4）。
6. **`DSG`/`CHG` 出线**：短、粗一点（它们是驱动脚不是电源，但别细于 0.3mm），⛔ 不与 `PACK_P` 平行长走。
7. **I²C**：SDA/SCL **等长、并排**，串阻靠排针侧。
8. **测试点**（**放置 → 测试点**，直径 1mm 左右）≥ 6 个：`PACK_P`、`PACK_N`、`CELL1`、`CELL2`、`CELL3`、`REGOUT`、`AFE_ALERT`、`SRP`、`SRN` —— D6/D7 全靠它们，事后补不现实。
9. **丝印**（TopOverlay / BottomOverlay）：`T0 − ~ T4 +` **逐脚标 + 极性**；`Rsns` 旁印 **`5m0 ±1% / ≥5W`** 与 **`SRP→电池侧`** 一行小字；板上印 `BMS-A v1 2026-09-25`。

### 4.4 检查（30 分钟）

1. ☐ **DRC（设计 → 检查 DRC / 设计规则检查）**：**必须 0 错误**（悬空飞线 = 网络没连上，⛔ 不许"先不管"）。
2. ☐ **1:1 打印或截图叠图**：把 §3.1.1 ① 的表放左边，右边放 PCB 俯视图，**用鼠标点网络名**（工具会把该网络所有焊盘高亮）逐个核对 20 个脚。
3. ☐ ⭐ **把线束顺序"演"一遍**：手指从 `T0` 走到 `T4`，嘴里念"先接 B−、逐串往上"（S18）。丝印错了现在就改，比接错炸芯片便宜。
